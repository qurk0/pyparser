# Проект: Импорт данных об успеваемости в БД

## Описание
Этот проект предназначен для автоматизации обработки данных об успеваемости, включая парсинг HTML и CSV файлов, управление учебными планами, дисциплинами, оценками студентов и результатами. Он интегрируется с базой данных PostgreSQL и предоставляет инструменты для анализа и внесения данных.

## Основной функционал
1. **Парсинг данных**:
   - `html_parser.py`: Извлечение информации о группе, дисциплинах и оценках студентов из HTML файлов.
   - `csv_parser.py`: Извлечение аналогичной информации из CSV файлов.

2. **Управление учебными планами**:
   - `ra_plan.py`: Создание и поиск учебных планов на основе уровня обучения и года поступления.

3. **Управление дисциплинами**:
   - `ra_disc.py`: Добавление новых дисциплин и поиск существующих.

4. **Управление формами контроля**:
   - `ra_control.py`: Создание записей о формах контроля для дисциплин.

5. **Управление оценками**:
   - `ra_mark.py`: Внесение оценок студентов в базу данных.

6. **Управление результатами**:
   - `ra_results.py`: Расчёт итоговых результатов студентов, включая рейтинг и процент выполнения.

7. **Версионность данных**:
   - `ra_version.py`: Создание записей о версиях данных для отслеживания изменений.

## Использование
### Запуск проекта
Для запуска проекта необходимо использовать `makefile`. Основные команды:
- `make start` — Запуск Docker-контейнера с базой данных.
- `make load file={имя_файла}` — Загрузка данных из HTML или CSV файла в базу данных.
- `make dump` — Создание дампа базы данных.
- `make stop` — Остановка работы контейнера.
- `make restore` — Возобновление работы остановленного контейнера.
- `make reset` — Пересоздание контейнера с базой данных.
- `make help` — Вывод списка всех команд, доступных для работы.

### Подготовка к работе с проектом
1. Скачиваем репозиторий проекта
2. Заходим в директорию с проектом. В терминале вводим команды:
   `python3 -m venv venv` - делаем виртуальное окружение
   `source venv/bin/activate` - запускаем работу с виртуальным окружением.
   `pip install -r requirements.txt` - установка зависимостей проекта
3. Вводим команду `make start` - для запуска Docker-контейнера с БД PostgreSQL, она нужна для работы парсера
4. `make load file={название файла}` - парсер считывает нужный файл (либо .html, либо .csv), считывает оттуда данные, обрабатывает их и вносит итоговый результат в БД.
5. Наслаждаемся результатом

Важно уточнить, что во время выполнения работы было оговорено, что в БД таблицы students, students_to_groups и groups уже существуют, поэтому данные оттуда проект никак не модифицирует, а данные о дисциплинах поставляются в ручном режиме (проект автоматически их никак не добавляет, это тоже оговорено)
